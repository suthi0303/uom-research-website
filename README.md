# University of Moratuwa Research Homepage (Streamlit)

## Run locally

1. Install Python 3.10 or later.
2. Open a terminal in this folder.
3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Start the website:

   ```bash
   streamlit run app.py
   ```

The homepage uses local image assets in the `assets/` directory, so it does not depend on external image hosting.

## Customisation

- Replace the images in `assets/` with approved University photographs and research images.
- Update the navigation links, feature descriptions, and news items in `app.py`.
- Connect the search box, subscription form, and content links to the University's actual services before production deployment.

This is a front-end prototype. The Learn More button and content links are placeholders until connected to real pages or a backend.
